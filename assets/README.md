Assets module

This folder contains static resources for the application:

- `css/style.css` — main public stylesheet.
- `css/admin.css` — admin panel stylesheet.
- `css/forms.css` — shared form styles.
- `css/responsive.css` — responsive layout rules and media queries.
- `images/` — placeholder directories for logos, hero images, about section images, gallery images, icons, and backgrounds.
- `fonts/` — placeholder directories for Poppins and Open Sans font files.

The CSS files are structured to separate public styling, admin styling, forms, and responsive behavior. No JavaScript is included in this module.
